Help — How cross-source correlation works

Reuses the patterns already found by Find Patterns on each source — it doesn't re-read log files or re-cluster anything. Each pattern's time range comes from whichever of its own lines had a parseable timestamp (ISO-8601 only, e.g. 2026-07-20 08:12:03); a pattern with no parseable line simply can't take part in correlation.

Two patterns from different sources are grouped together when their time ranges overlap within the window (10 minutes by default). If pattern A overlaps B, and B overlaps C, all three land in the same group even if A and C don't directly overlap — a spread-out incident touching several tools over a few minutes shows up as one finding rather than being split apart.

Running this replaces the previous correlation results for the whole project — it's a fresh look at the current set of patterns, not an accumulating history.
